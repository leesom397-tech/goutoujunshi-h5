# 互动循环与修复复盘：从具体片段到下一步

## 先用这六条

1. 只描述可见行为，区分原话、推测和未知。明确拒绝按拒绝理解；不从一句冷淡推断人格、依恋类型或隐藏的爱意，不生成被爱指数。
2. 用一个具体片段复盘：触发了什么 → 双方分别做了什么 → 是否有人尝试修复、如何回应 → 后来实际发生了什么。缺失环节写未知；至少出现多个可核对片段，才称为反复循环。
3. 修复分开记录：发出尝试、收到回应、达成具体约定、约定实际兑现、后续未知。说了抱歉或发来表情，不等于问题解决；没有回应也先核对时间与上下文。
4. 区分支持意愿、当时能力和支持方式。慢回复不能单独证明不在意，提出暂停也可能是在调节情绪；看有无约定何时回来、之后有没有回来。
5. 只给一个当前优先行动，附自然话术、适用时机和可观察的后续。用双方约好的事件或时间复查，不套统一的三天或两周期限。明确拒绝、伤害或越界时尊重边界，不用追逐证明诚意。
6. 威胁、暴力、胁迫或自伤风险优先走现有安全与求助指引；不等待统计阈值或第二种证据才响应。以下是讨论工具，不是诊断、成功率或科学评分公式。

## 与已有指南的分工

投入多少、何时降级投入，沿用《关系投入校准》；冲突时怎样表达，沿用《沟通冲突与修复》；可发送的回复和正面、模糊、拒绝分支，沿用《实战话术编排器》。本指南补足“发生过什么、修复到了哪一步、下一次核对什么”的复盘结构，不重复建立评分体系。

## 把追退模式还原为片段

用户说“我越问 TA 越躲”时，先取最近一段有顺序的原话，不急着定义谁是焦虑型或回避型。可整理：

| 环节 | 可以记录 | 不能补写 |
| --- | --- | --- |
| 触发 | 临时取消、询问关系、提出需要；原话与已知日期 | 谁故意试探、谁害怕被抛弃 |
| 双方反应 | 谁重复追问、谁解释或暂停、是否约定恢复交流 | 把沉默一律解释为惩罚或爱意 |
| 修复与承接 | 道歉、解释影响、给出改约；另一方是否回应 | 单凭语气柔和认定已经和好 |
| 后续事实 | 到约定时间有无回复、约定是否落实 | 用未来可能发生的事填满结局 |

保留可替代解释：忙碌、信息漏看、需要降温、意愿不同等。只列与材料相关的可能性，不把它们当成替对方开脱的定论。一个片段只支持本次观察；反复模式需要多个片段，且说明材料可能经过选择。用户指出记录不全或说话人归属错误时，先修正事实。

例如：用户连续追问见面，对方说“今晚赶项目，明晚我确认”，第二晚是否确认未知。可见的是追问和一次有返回时间的暂停，不能认定冷暴力。下一步可以是“好，你明晚确认就行；如果时间不合适，我们再约。”之后核对确认是否发生。若对方已明确说不想见面，则接受拒绝，不能把同一句话术用于继续施压。

## 修复状态不等于修复分数

- 发出尝试：承认影响、澄清误会、主动降温、请求重开话题、提出可兑现的改约。记录具体做了什么。
- 收到回应：对方看见、回答、表达仍有不舒服，或暂时未回应。收到回应不代表已经同意。
- 达成约定：双方明确同意一件具体改变，例如临时变动提前告知；单方面承诺只记为承诺。
- 实际兑现：在下一次相关事件中，是否完成约定；没有后续材料就写未知。
- 仍待处理：哪些影响、分歧或边界仍未谈清，可与已经兑现的部分同时存在。

这些是观察项，不强制排成一条只进不退的流程。一次失败不能定义整个人，反复口头道歉却无行动也不能反复当作“已修复”。不以截取的聊天计算修复成功率，不将道歉次数当作爱的程度。

## 情绪支持：意愿、能力、方式分别看

意愿看有无承接需要或明确回应；能力看是否明确说当前忙、疲惫或做不到；方式看双方需要的是倾听、陪伴还是一起想办法。三者不能互相替代。愿意帮忙但不断给建议，可能与“我只想被听见”的需要不匹配；可以先问“你现在更希望我听你说，还是一起想办法？”

对“我每次难受都找不到 TA”，可核对：用户有没有表达需要、对方有没有看见或说明限制、是否给出另一个可联系时间、之后是否兑现。记录具体情境，不从线上可得性推断整个人的情感能力，也不要求任何人全天候响应。

## 互动失衡要看机会与兑现

消息数量不等于实际投入，连续短句也不能算多次主动。分别看双方有机会表达需要、安排见面、寻求帮助或发起修复时，是否回应、协商和兑现。材料只展示用户求助的一次情境，就不能推出长期单向支持。某一段的投入可能不对称；关键是是否能谈清、是否得到尊重和是否持续由一方承担。

用户说“每次都我道歉”时，找具体事件：各自承认了什么、谁提出了可执行改变、谁执行了。允许“道歉更多，但双方都在行动”与“口头回应很多，实际约定总落空”这两种不同结论。不要制定固定 50/50 标准，也不要把对方的经济支出当成感情证明。

## 让下一步能被复查

建议中优先包含：当前目标、适用时机、一句可发送的话、接下来核对的具体行为。只选择当前最需要的一步，不强制输出三件停止、三件开始或五条发现。

- 有承接：说明哪些信息已确认，再协商一个实际安排；不要把礼貌回应升级为关系承诺。
- 含糊或暂未回应：先保留未知；在双方已约好的节点核对一次，避免连续催促或自行测试忠诚。
- 明确拒绝或不舒服：停止该方向的推进，尊重对方也保留自己的边界。
- 约定反复落空：引用具体例子表达影响和需要，结合已有投入指南讨论调整；不依据固定天数替用户决定分手。

沿用产品现有 observation / judgment / nextStep、证据与其他解释字段，以及用户主动提交的行动反馈。反馈区分建议本身、实际行动与真实结果；未知保持未知，不自动改写历史评分。
