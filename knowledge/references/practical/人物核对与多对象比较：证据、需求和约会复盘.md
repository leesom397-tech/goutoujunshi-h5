# 人物核对与多对象比较：证据、需求和约会复盘

## 先用这六条

1. “前后矛盾”需要同一人的两条可比原话，各有来源与时间；原文缺失、时间未知、只有转述时，标为待核对，不断言撒谎。先排除生活变化、口误、玩笑、转述、截图错序和说话人混淆。
2. 核对只问与当前关系选择有关的问题：先说明自己真实的需要，再问一个中性问题，允许对方不回答。不要编造自己的经历换取披露，不索取住址、密码、证件或跟踪定位。
3. 多对象比较先列用户明确的需要与边界，再逐人记录已知、来源时间、未知和可能影响。资料少不等于更差；消息多不等于更适合。不得强制排名、补零分或造综合人格分。
4. 约会后分四格：发生的事实、用户自己的感受、仍待验证的问题、一个下一步。感受值得重视，但不能反写成对方原话或真实动机。
5. 居住区域、交通工具、手机新旧、消费金额、职业和外貌，不能证明诚信、收入或人格。尊重隐私或不熟悉术语，也不能单独认定欺骗。
6. 明确拒绝优先于旧推测；威胁、暴力或资金诱导先使用既有安全指引，不等凑齐“矛盾条数”。本指南提供证据结构，不提供诊断、固定观察期限或真实爱意概率。

## 实质增量与已有原则的衔接

产品已有互动、沟通、边界、关系期待、适配与风险等观察维度，也已有原话优先、反读心和低压力沟通原则，不再增加八维评分卡。本指南补充可操作的双记录核对表、个人需求比较表，以及约会后四格复盘。它们可放进现有 judgment、evidence、alternative、nextStep 或聊天回答中，不要求新增接口或模型分数。

## 先核对两条记录是否真在说同一件事

| 栏目 | 应当记录 |
| --- | --- |
| 记录 A | 原话、说话人、聊天/资料/用户转述等来源、明确日期或日期未知 |
| 记录 B | 同样四项，不能用模型旧结论代替第二条原话 |
| 可比性 | 是否同一人、同一含义、同一时间范围，还是工作/住所/关系状态已经变化 |
| 差异 | 两句话具体哪里不一致，分别还允许什么合理解释 |
| 当前结论 | 已解释、待核对、或两条材料目前无法同时成立；不直接升级为“骗子” |
| 最小核对 | 一个不诱导、不越界的问题，以及回答后需要更新的判断 |

可比字段包括年龄、所在城市、职业角色、收入时间范围、资产归属、婚恋状态、账号自述。字段本身不是风险结论。年龄先排除虚岁、周岁和记忆偏差；地点先区分居住、旅行、转发与照片拍摄时间；职业先区分换工作、兼任和职位称呼；收入先区分税前、税后、单月、年收入与营业额；资产先区分自有、租赁、家庭共有与已转让；婚恋状态与账号归属需要本人明确说明，不能只靠同款照片断定同一个人。

例如，10月1日“我在杭州工作”和10月8日“这周上海出差”可以同时成立，不能记作矛盾。若两条同日原话分别说“我目前单身”和“我和伴侣约定了周末见面”，可标为关系状态待核对，仍需确认“伴侣”所指、引述背景及记录归属。以上均为合成示例。

## 自然核对：真实需要 → 中性问题 → 留出选择

只从用户已表达的需要组织话术，没有自述就直接问，不替用户编生活史：

- 状态：“我想确认我们对关系状态的理解。你之前说目前单身，后来提到伴侣，是我把上下文理解错了吗？”
- 城市：“我比较在意以后能不能稳定见面。你现在主要在哪个城市生活，另一边是出差还是有长期安排？”
- 工作：“我对你提到的工作还不太了解，愿意聊聊平时主要做什么吗？”
- 相处期待：“我希望先慢慢了解，再一起讨论下一步。你比较希望怎样的节奏？”

不要把热情接话当成已验真，也不要把暂时不想聊当成撒谎；记录得到的新信息和仍然未知的部分。核对没有“零攻击性、答案一定真实”的保证，可以承认问法可能让人不舒服并调整。禁止灌酒后套话、尾随、假账号、强看设备或用第三方隐私来查证。

## 按自己的需要比较，不评谁更有价值

先使用用户主动填写或本次明确说出的需要。未表达就标为未明确，必要时问一个最影响决定的问题；不要默认必须结婚、生育、同城或特定性别。

| 用户的明确需要 | 对象 A：已知与依据 | 对象 B：已知与依据 | 未知与下一步 |
| --- | --- | --- | --- |
| 希望稳定见面 | 例：已确认每周末可安排；注明原话日期 | 例：目前异地，尚未讨论安排 | 先问是否有双方可接受的见面节奏 |
| 尊重不临时改约的边界 | 记录实际事件与回应 | 同样标准，不因消息量不同直接排名 | 尚无此类事件就写未观察到 |
| 对关系目标的期待 | 分开记录双方明确态度 | 分开记录，不把模糊承诺当匹配 | 明确不一致与资料未知要分开 |

表格只是格式示例，不能将示例填入用户真实档案。每个人先独立分析，避免把甲的原话、感受、报告或边界混给乙。聊天量、认识时长和资料完整度影响判断把握程度，不是分数加成。已有互动信号或适配值只解释其已知材料范围，不能混成“最优伴侣”指标。可以给核对顺序与选择代价，不能替用户决定谁应出局；明确危险除外，先保障安全。

## 约会后的四格记录

1. 事实：什么时候、约好了什么、实际发生什么；没有明确日期就保留未知。区分用户亲历、聊天原文和推测。
2. 感受：用户说自己放松、紧张、开心或被忽视；不猜对方的内心，也不贬低用户感受。
3. 待验证：哪一件事还缺上下文，有什么其他解释；不要为了写成“破案”故事制造伏笔。
4. 下一步：继续了解、询问一个问题、说明边界或停止推进中，选择当前最必要的一步；尊重双方的意愿。

可把实际行为与结果提交到既有行动反馈，发生日期与记录日期分开。若用户只想写私人复盘，保留自己的口吻，不虚构对话、身体细节、约会次数或关系结局；需要对外分享时用代号并去除可定位的细节。不自动公开或导出资料。
