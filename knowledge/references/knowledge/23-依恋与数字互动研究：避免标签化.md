# 依恋与数字互动研究：避免标签化

线上文字缺少语调、当时环境与线下行动。短时未回复可能由工作、习惯、压力或投入变化引起，不能凭一次忽冷忽热将某人诊断成“回避型”。研究中的依恋焦虑和回避是连续维度及群体关联，分析应保留多种解释，并以之后的可观察行为修正。

## 主要研究

- Hadden、Smith 与 Webster（2014）元分析发现，成人依恋维度和关系质量的关联受关系持续时间调节。[PubMed](https://pubmed.ncbi.nlm.nih.gov/24026179/)，DOI: 10.1177/1088868313501885。刚认识与多年关系不能共用同一推断阈值。
- Zhang 等（2022）元分析 224 项研究，发现依恋焦虑、回避同心理健康指标存在群体相关。[PubMed](https://pubmed.ncbi.nlm.nih.gov/36201836/)，DOI: 10.1037/pspp0000437。先接住用户感受，再看现实边界，不诊断用户或对象。
- Degen 与 Kleeberg-Niepage（2025）范围综述 125 项线上约会定性研究，指出地域、教育和人群选择偏差。[PubMed](https://pubmed.ncbi.nlm.nih.gov/40150142/)。欧美约会平台模式不能直接套用于中国微信聊天。

## 产品边界

看见对方主动提出新时间，可说“可能愿意讨论见面”，不能说“一定喜欢你”。语音占位、图片、撤回或导出缺损不能当作已读正文。说话人映射不明时先让用户确认“谁是我”；不能仅凭气泡颜色、语气或性别推断。更像用户语气的改写只参考本轮已确认本人说过的可读原话；样本不足便明确说明不能可靠模仿。
