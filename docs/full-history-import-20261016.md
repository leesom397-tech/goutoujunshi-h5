# 单联系人完整聊天导入与入口简化

## 用户可见变化

- 网页聊天导入不再选择“最新 N 条”。点击一次，自动读完当前电脑上该联系人的历史，包含可读取的语音转写。
- 首次完整导入；暂停、网络中断或刷新后继续原位置；已完成后默认补充新聊天。同步手机旧记录后可重新核对全部历史。
- 助手 1.2.0 的“打开网页并连接”使用一次性连接凭据；网页消费前立即移除 URL fragment。长效令牌仅在当前标签页保存，手动连接码作为备用。
- 首页聚焦问成子和完整分析；人物、对照、最近报告靠前；导航与材料入口合并，保留历史和基础信息对照。
- 新手桌面引导为连接助手、选好友导入两步；材料入口根据设备推荐。

## 完整性的实现

每页 500 条是内部传输批次，不是总条数限制。所有分片按稳定排序读取，游标绑定微信账号、联系人和固定快照。当前页文本与语音可先保存，最终页提交 IndexedDB 后才推进游标。取消时保存刚完成的语音，重播当前页自动去重。

增量快照按各分片 rowid 上界处理，能找到迟到的旧日期消息及新分片。发现来源、账号或游标不一致会停止，不会混入其他人的材料。没有持久化或上传数据库密钥。

去掉本地资料库两万条总量限制；修复同秒分页边界错序。云同步按 100 条上传、500 条下载，拒绝异常游标、重复 ID 或不一致的总量。实际容量仍受用户浏览器磁盘空间限制；失败保留已提交页。

完整导入与付费分析分开。原文、语音和完整聊天统计先保存在本机，跨端同步仍由用户启用，分析仍要求确认所选材料与费用。超过两万条时完整聊天统计仍在本机展示；为限制请求体，本次报告明确提示不附带全历史逐条统计。

- 真实 Chrome IndexedDB 合成 21503 条、44 页；完整本机统计、216 批云上传与 44 页下载往返一致。
- 浏览器合成集成 1203 条三页自动导入，刷新连接、失败续读、去重、401 清理；1280 / 390 布局检查。
- 首页、问成子、材料入口、分析类型与两步引导浏览器验证。
- 助手 1.2.0 冻结程序语音及数据库合成自检通过；安装资源分块与摘要校验通过。
- 冻结助手真实按钮 → 一次性凭证兑换 200 → 会话校验 200 通过；验证使用本机内存转发适配器把系统浏览器打开请求交给隔离测试浏览器，未改变产品流程，凭证未落盘。
- 真机授权联系人验证通过：636 条消息自动读取两页（500 + 136），110 条语音全部有文字，缺少本机语音为 0；耗时 16.11 秒，复用已有语音转写缓存，不代表新语音首次转写耗时。

本机没有的手机旧聊天，需要先通过微信导出/同步到电脑；仅用于恢复的备份包不等同于已导入电脑的聊天。Windows 支持本地数据库后台读取；Mac 目前保留窗口采集入口。
