# 成子网页与小程序逐页核对

日期：2026-10-09。网页已发布版本 `3e180068-fe81-401b-b3f6-53a74275a1ad`，15 项匿名线上检查通过。最终部署与原生预览状态以 `web-parity-release.md` 和 `outputs/web-parity/release.json` 为准。

## 范围与结论

本轮以小程序 `app.json` 声明的全部 9 个页面为清单，检查业务入口、请求参数、权限、计费、结果字段、人物归档、恢复流程和视觉呈现。网页沿用同一后台业务处理器，同时采用独立网页账号。发现的实际缺项已修复；这不表示所有设备、真实模型回答或微信审核结果都已经验证。

## 界面统一

网页主页面与资料库、历史导入、定位、个人资料、旧分析入口和账号关联等辅助页面采用同一明亮玻璃风格。小程序 9 页、共享导航、忙碌指示、信号标签、头像选择和朋友圈报告同步配色、图片和文字层级。沿用用户确定的原始蓝色 Orbit 标志，不增加卡通图案。

针对用户最新的“看清楚、分主次”要求，主标题/结论、正文、字段标签、辅助说明分别设置字号与字重，并提高实色文字对浅玻璃的对比。网页正文通常 15px、表单 16px，辅助 12–13px；小程序正文 27–29rpx、辅助 24–26rpx、章节 32–36rpx，Canvas 文字 12px。两端对照项目列在横向滚动时固定。最终独立网页计算样式与人工复核见 `outputs/readability/review.md`。

小程序仍用微信原生 Canvas / picker / 录音 API；网页使用 SVG / 浏览器表单 / 音频 API。数据含义与操作结果一致，平台控件不会像素相同。只有真实可计分的数据参与适配和趋势，缺失值不会被补成 0。

## 两份参考方法的实际使用

两份固定版本参考经去重后改写为 2 份共享指南，知识包合计 50 份文档。它们通过真实检索和提示构造进入两端的分析与军师流程，来源及许可记录在 `skills-adoption.md`。

- 互动循环：触发、双方动作、修复回应、实际兑现。
- 人物核对：两条原话的来源和时间、合理的其他解释、一个中性核对问题。
- 多人比较：按自己的需要查看已知、待确认和未知，保留证据与日期；不制造排名。
- 约会复盘：事实、自己的感受、待验证、一个下一步。

## 明确的运行边界

1. 网页账号与微信身份是不同认证入口；浏览器不实现微信手机号授权，关联走已有账号关联流程。
2. 收款仍由客户联系 lxlikex，管理员核对后分别开通积分和权限；没有自动支付回调。
3. 本机未传完图片、窗口草稿和可选最近对话依赖当前浏览器存储，不声称跨设备自动同步。
4. 功能回归使用合成材料和模型响应，没有消耗生产客户积分；真实 AI 回答质量没有由这些测试证明。
5. 官方微信模拟器已经使用用户扫码后的有效登录验收。真实手机麦克风、扬声器回声和语音上游质量仍需真机检查。
6. 小程序临时预览、上传体验版和正式审核发布是不同步骤；最终交付记录分别注明，不把本地源码更新当作已发布。
