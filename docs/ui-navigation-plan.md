# 界面与操作层级 · 2026-10-06

目标：用户先完成眼下的判断和行动，再按需深入；不通过删除知识库、图表或资料来缩短页面。

视觉：关系观察手册（Editorial）；米白 #F6F3EC、墨色 #142633、绿 #276D5B、琥珀 #B78332；PingFang SC / Microsoft YaHei；左侧标题与内容，右侧状态或轻操作，沿用图标与克制动效。

| 原入口/内容 | 新位置 | 保留与迁移规则 |
|---|---|---|
| 首页底部长链入口 | 截图分析后、知识库前 | 人物跟踪、问军师优先可达；知识库统计和来源保留 |
| 我的档案 | 首页独立轻入口 + 档案切换 | 只进入 self，不选择其他人物 |
| 人物名单内嵌详情 | 同路由带 subjectId 的独立页面栈 | 系统返回回名单；旧深链不失效 |
| 人物详情长页面 | 关系概览 / 人物资料 / 互动趋势 | 结论、适配与行动；基础资料与编辑；六维与日期趋势分别归属 |
| 待确认资料长列表 | 顶部计数入口展开 | 人物详情只核对本人物；我的资料只核对本人 |
| 全局暂停/撤回/清空 | 档案管理与隐私入口 | 功能与确认防护不删除；暂停时明确提供恢复入口 |
| 报告完整文本 | 结论/下一步优先，细节展开 | 判断依据、适配细项、逐句解读保持可达；回复可复制 |

实施顺序：首页入口 → 档案列表/详情 → 报告渐进展开 → 运行截图检查。新建、编辑和删除流程维持原权限与接口，未发布前仍需真机验证返回、键盘、字号和状态保留。
