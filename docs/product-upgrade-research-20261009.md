# 成子产品升级：研究与落地建议

日期：2026-10-09。范围：网页工作台、导航、分析结果、人物档案及行动反馈。本记录提出设计与验收方案，不表示相关改动已经实现或上线。

## 已有基础与最值得补的断点

只读检查 `app/workspace/page.tsx`、`components/WebNav.tsx`、`components/ArchiveFeedback.tsx` 和 `components/ArchiveInsights.tsx` 后：当前首页有完整功能入口、注册弹窗、上传任务恢复和积分余额；人物页已有真实反馈、日期更正及证据/其他解释。主要断点是用户回来时仍先看到宣传长页，行动与结果分散在不同入口，功能查找依赖记住导航名称。

本轮优先把已有能力串成“带来材料 → 看懂依据 → 选择下一步 → 记录结果 → 继续判断”的流程。保留用户认可的明亮玻璃光影和线条关系标志。研究提供交互依据；不复制参考产品的品牌、文案或视觉素材。

## 建议的界面与操作结构

### 1. 首页根据登录状态服务不同任务

- 未登录：沿用明亮品牌展示与真实功能预览，点击功能在当前页面打开注册；注册后继续用户原来选择的功能。
- 已登录：首屏显示“继续上次”和三个主要入口：分析新材料、问军师、人物关系。下一屏按真实数据呈现最近人物、最近报告、待回顾行动。没有数据时提供一个明确的首个任务，不用虚假计数填满仪表盘。
- “联系开通”和积分留在账户或清晰的辅助位置；积分不足在提交前说明本次费用及开通路径。

### 2. 高频入口按用户任务命名

首页入口可用“看聊天 / 看朋友圈与主页 / 想想怎么回复 / 接着聊这段关系”。进入后仍保留聊天、朋友圈、社交资料各自模式的区别，不因入口合并改变分析接口或费用。

导航保持稳定；人物详情、报告和语音显示当前位置及返回入口。返回人物列表时保留搜索/筛选；手机底部导航不遮住提交按钮。全局搜索既能找功能，也能从人物回到相关记录。

### 3. 结果强调依据与可执行性

“当前判断”使用基于材料的观察语气，呈现另一种合理解释和待验证点；分数是辅助线索。“下一步”给一项可执行建议或一句可复制回复，提供更稳妥/更直接的表达切换时说明目的，避免生成操控他人的策略。

延续当前证据折叠与事实确认机制。未知资料保持未知；照片可见信息不能直接当作收入、婚姻状态等事实；反馈进入后续上下文时需保留它是用户回报的结果。

### 4. 页面状态先完整，再添加装饰

每个入口覆盖加载、空内容、成功、失败、身份过期、积分不足和恢复中。主按钮有可读对比度，禁用态仍读得出文字；触控目标建议至少 44px。正文建议 15–16px 起，长报告 1.6–1.75 行高，说明与正文用颜色和间距拉开层级。这些为本产品起始设计值，应通过手机截图和实际阅读调整。

## 本轮实施优先级

1. 登录工作台、查找入口和最近记录：减少重复找功能、重复讲背景。
2. 分析输入及结果的任务层级：确保从材料到行动完整、可恢复、收费透明。
3. 人物列表/详情的搜索与分组，并把已有反馈入口带回工作台。
4. 统一状态、字体、触控、动效和减少动态效果模式。

验证优先走真实主要路径：游客选择功能→弹窗注册→继续；已登录→选人物→分析→查看证据→复制/反馈→再次进入；失败或会话过期→恢复。用合成数据检查跨人物和跨账号隔离，禁止拿真实客户记录做截图演示。

产品效果仍需用户验证，可观察首次任务完成率、完成用时、返回后找到最近任务的时间、失败恢复率；仅采集必要的功能事件，不采集原始聊天内容。上述指标不代表现在已经接入或改善。
