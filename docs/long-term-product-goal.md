# 成子关系决策智能体：长期优化目标

## 目标与交付边界

用户已要求全面优化并设置长期目标。核心价值：结合用户自己的需要，持续判断关系变化与下一步；不是堆积报告或制造“读心准确率”。

保留已有档案与知识库；未经单独授权不提审、不正式发布、不接入收费、不用个人关系材料训练跨用户模型。开发包和临时预览码必须明确标识版本。

## 实施顺序

1. 行动卡与结果反馈：按人、按报告保存，身份与同意保护，幂等，保留更正轨迹。
2. 真实关系事件：事件发生日期和材料导入日期分开；去重不吞真正重复发生的互动。
3. 判断更新：上一判断、新依据、保持/修正的理由、下一步；无可比材料不画虚假涨跌。
4. 个人画像：明确资料、偏好、候选观察分层；允许查看、纠正、暂停、删除。
5. 知识与场景：按场景选择方法，连到原话依据和具体行动；规则升级用固定案例验证。
6. UI：四个重点——现在怎么看/哪里变了/与你合适吗/下一步；明细按需展开。
7. 综合回归、开发工具运行验证、生产部署检查、候选包上传与码；真机未验项明确列出。

## 衡量价值（待用户测试，不宣称已证实）

- 首次分析能否给出一个具体有用的发现与行动。
- 第二次带回新材料时是否能解释判断为何改变。
- 一周后是否无需重新讲背景，且档案无串人。
- 用户是否认为节省时间、帮助决策，而不是更焦虑、更依赖分数。
- 复用与付费需要真实用户实验，不用模型分数或功能数量代替。
