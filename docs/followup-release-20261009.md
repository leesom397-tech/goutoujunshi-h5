# 功能跟进与原图恢复 · 2026-10-09

用户要求继续优化功能，并恢复之前的图片。本轮保留暖米白界面，恢复原玻璃双环；将已有行动反馈从人物档案接到报告、首页及继续咨询。

## 交付内容

- 首页显示最近可用报告，“继续上次分析”与“上传新材料”分开；新增“后来怎么样了”，展示真实归档建议与明确记录的结果。待反馈总数不受首页三张卡、最近四十位人物限制。
- 报告末尾支持六类实际结果、备注与事件日期。明确确认后免费保存，可更新；失败重试复用反馈 ID。继续咨询主动带入原建议与实际结果，不自动发送或扣费。
- 首页及报告的“记下进展”直达对应人物、对应建议，并自动展开编辑器。人物档案的快捷结果按钮改为先选择，再确认保存，避免误触写入。
- 新增“聊聊后来的进展”场景：实际行动、对方真实行为、自己的感受、现在的疑问。保留可编辑草稿与发送费用提示。
- 修复咨询断线重试遇到摘要到期时丢失原请求 ID 的问题；已提交的请求保留人物、请求体及 ID，刷新后仍可取回。新请求继续检查摘要期限和账号、人物一致性。
- 修复语音结束后更换人物，再转文字咨询会关联错误人物的问题；追问固定使用实际通话时的人物。
- 网页与小程序源文件恢复 `relationship-daylight` 原玻璃双环，保留暖米白配色与现有动态效果。
