# 问成子与公共案例更新 · 2026-10-16

## 已完成

- 网页 `/chat` 改为「问成子」，导航、工作台和搜索入口同步命名。
- 截图、粘贴图片或文字 + 具体问题直接获得短答；最多 3 张，明确选择本人左右侧，发送前确认千问处理范围与 5 积分费用。
- 图片只用于本次问题和后续追问，不生成完整报告、不写入人物记忆。当前窗口可恢复截图，长期本地对话记录剔除图片。
- 原请求失败重试保留编号；相同侧重复点击不丢失编号；删除最后一图后重新核对身份；换人、新对话、换账号清理截图。
- 首页首屏展示互动与行动、双侧共同点、前后变化，标明 135 条参考来源、约 8.4 万字及心理学/法学/社会学。
- `/examples` 公开复用当前三类报告组件：四部分阅读、逐句高亮、互动仪表、双侧共同点、说法与行动、期待差异与免费回复演示。全部使用虚构数据。
