# 逐句聊天解读

入口：https://coach.lovetalk.love/crush

## 已实现

- 手机/桌面气泡下的语气、可能意图、证据不足提示。
- 识别「我：」「对方：」、两人昵称与微信桌面时间格式；未知说话人或多人记录要求纠正，不猜身份。
- 对象级近期上下文、追加分析、可信重复片段去重、请求幂等和同会话并发锁。
- 已有千问做文字解读；Jev 专用接口处理分类分布，未配置时不能选择 Jev。千问不显示虚构百分比。
- 用户可一次性单独开启完整分类：新报告先由千问给出判断，再将本报告最多 80 句、每句最多 160 字的可读文字摘录发给 TypeSafe AI 补全全部情绪与意图类别；原截图、语音文件和完整关系档案不发送。旧报告只在用户打开时补全。此授权独立于旧的 6 句快判断与 40 句六维授权，可随时关闭后续发送；正在处理时撤销则不保存补全结果。网页完整展开条形分布，微信首条快判断保持简短。
- 网页和手机浏览器可在完整逐句报告前单独选择第三方快判断：只发送最多 6 条近期、已确认说话人的文字；选中对象时可带入该对象最近 7 天已分析的短期聊天，不发送长期档案，也不为快判单独保存原文。用户授权可撤销，每账号每日上限 60 次。
- 结合既有关系知识库和用户已确认档案生成回复建议。
- 私有报告、7 天可访问期限、定时清理、撤销及删除。
- 网页保存分析图使用本机 Canvas 生成 JPEG，不需另配图片账户；生成后提供手机长按保存预览。微信服务器回传图片使用安全 HTML → Cloudflare Browser Run，最多展示最近 4 条；原文转义、禁止网络资源与脚本。
- 临时聊天使用独立会话 ID，可用「新聊天」从头开始；历史报告显示对象名称并恢复原会话，微信报告也能在网页继续追加。未登录时先看示例，登录回跳保留报告链接，不先收集真实私密聊天。
- 微信客服在图片识别前确认收到；识别后先发一条含逐句作用和具体解释的短判断，再自动发送彩色逐句图。彩图上传失败只发一条简短状态和网页报告链接，不重复整段文字。识别与绘图、上传分阶段记录耗时及无隐私错误阶段；微信图片识别当前 40 秒截止，仍存在偶发超时，不能将固定测试图成功等同于真实长图验收。长图可发「第2页」继续。文字回复、网页详情、分段收集与「怎么回」保持可用。不支持修改微信原生气泡或原生引用回复。
- 网页 `/crush` 可直接选择手机相册里的 PNG/JPG 单聊截图，先核对本人气泡侧、材料提供权和图片识别同意；报告沿用当前对象及会话，微信报告打开后也可在网页续接。原图不存入长期档案。
- Android 支持将已安装的 LoveTalk 网页应用作为系统“分享图片”的目标：正常受 Service Worker 控制且已登录时，截图与当时的账号 ID 绑定，暂存在手机浏览器的同源本机缓存，进入 `/crush` 后再次核对账号、气泡侧与材料提供权；确认前不调用图片模型，账号不一致即删除，读取后即删除。本机最多保留 3 张待处理分享图，超过 15 分钟拒绝读取；下次打开应用或再次分享时按当前登录账号清理，退出或切换账号也会清理。未登录时要求先登录再分享；若浏览器未受 Service Worker 控制，分享 POST 可能到达站点，但服务端不读取、不保存、直接提示改用文件选择器。iOS 不宣称支持此系统分享入口，仍可从相册手动选图。同源缓存不是防止同一浏览器中恶意脚本读取的加密保险箱，线上仍须防 XSS 和共用设备风险。
- 微信拉取先写持久化 inbox 再提交游标；2026-09-29 起，回调和定时补拉使用独立 `goutoujunshi-wechat-pull` 队列，在拉取任务中向已授权截图尽早发送回执；耗时分析、记忆提示使用原 `goutoujunshi-wechat` 队列。两个队列由同一 Worker 消费，旧队列中尚未处理的拉取任务仍兼容；Durable Object 按客服游标/用户分别串行。双队列的绑定已在线核对，但不等于多用户负载与真人回执时延验收。
- 发件箱识别发送成功、明确拒绝、网络结果未知。未知结果不自动重发，避免刷屏；代价是极端故障时可能少收到一条，网页报告仍可查看。
- 未处理微信消息缓存约 1 小时，处理完成擦除原 payload；没有保存原截图或原录音。

## 仍需账号配置，不能视为已联调

线上已有 DASHSCOPE_API_KEY 和 JEV_API_KEY；第三方快判断另需用户单独授权。可选 JEV_MODEL（默认 jev-latest）。千问 key 不能替代 Jev key。

微信使用企业微信「微信客服」官方通道，不是个人微信机器人。需要 WECHAT_CORP_ID、WECHAT_KF_SECRET、WECHAT_CALLBACK_TOKEN、WECHAT_ENCODING_AES_KEY、WECHAT_KF_ID 和可选 WECHAT_KF_URL。回调地址：

https://coach.lovetalk.love/api/wechat/callback

首次开通分两阶段：先配置企业 ID、Token、EncodingAESKey，GET 只检查这三项并验证签名/解密；回调验证通过后，再取 API Secret 和客服账号 ID。POST 收消息仍要求完整配置，不能把握手成功视为已经能收发。

本地操作脚本 scripts/setup-wechat-callback.mjs：prepare 企业ID 生成 outputs 下被 Git 忽略的私密复制页面，configure 用标准输入批量写入上述三项 Cloudflare secrets，verify 仅测试线上签名 GET。页面包含敏感参数，不能转发、截图、提交 Git 或发布。
