# 聊天、语音与账户计费对等审计

审计日期：2026-10-09。范围为小程序 `pages/chat`、`pages/voice`，网页 `/chat`、`/voice`，以及其共用的身份、积分、权限和后台开通链路。

## 对等结论

| 能力 | 小程序实现 | 网页实现与核验 |
| --- | --- | --- |
| 自然对话、最近上下文、人物档案 | `/api/miniapp/text`，最近 6 条上下文，服务端校验人物所属账号 | `/api/web/text` 复用同一处理器；相同提示词、资料上下文、模型参数及积分包装 |
| 原话分析、关系定位 | 共用 text 处理器支持对应模式；当前小程序主聊天以自然对话为入口 | 网页提供三个模式，支持 `mode` 入口与刷新恢复 |
| 报告继续追问 | 临时报告交接、30 分钟有效期、会话与人物校验 | 临时窗口存储、相同有效期、账号与人物校验；摘要分两段保留，刷新继续已有对话 |
| 草稿、复制回复、新会话 | 本机草稿、回复复制、清空草稿 | 按账号保存窗口草稿；用户主动勾选后保留最近 30 条；回复组件复用，新会话清空记录 |
| 录音转文字 | 30 秒 WAV、确认后转写、5 积分 | 30 秒 PCM→WAV、独立转写确认与重试；成功填入草稿，用户检查后发送 |
| 语音免提／耳机、自然插话 | 播放参考回声过滤、打断队列、实时字幕 | 新增同源过滤算法与模式选择；保留浏览器 AEC、静音、打断、实时字幕 |
| 语音档案范围 | 所选人物及同意参数，服务端加载所属档案 | 同一 `loadVoiceMemory`，显式人物同意；账号变化清空范围 |
| 语音生命周期 | 连接、就绪、录音、播放、3 分钟、挂断、离开页关闭 | 同一握手协议；新增设备自然停止、权限等待取消、重复就绪防护、关闭锁与资源隔离 |
| 语音降级为文字 | 文字入口 | 两端均携带已选人物；无人物时保留小程序原入口 |
| 身份与账号 | 微信 token 验证 | 独立网页账户 cookie 验证；两条身份通道不能互相伪造，档案始终归当前 owner |
| 功能权限、有效期、积分 | 共用积分账户与任务账本 | 共用账本；网页语音先读取最新权限、价格与可用余额，最终仍由服务端强制校验 |
| 后台人工开通 | 管理员名单与用户编号 | 网页后台经实际 SQLite 处理器测试：管理员、CSRF、UUID、审计记录、独立积分／权限操作 |
| 重试与退款 | 固定请求编号、防重、失败释放 | 固定编号和原请求体跨刷新重试；成功回执重放；已退款任务生成新编号；不允许重复执行 |

小程序与网页使用不同登录方式。对等指业务处理与权限规则一致，并不将不同身份的档案、聊天或积分自动混在一起。

## 本次修复的实质缺项

1. **账号切换污染窗口记录**：旧页面状态可能在新 owner 生效、恢复尚未完成时写入新账号的存储键。现在持久化要求 owner、已恢复 owner 和当前引用一致；账号变化同时清空人物、模式、上下文、重试体、录音与异步状态。
2. **人物入口重放旧请求**：原先从其他人物或报告入口进入时，可能恢复旧 `requestId/requestBody`。现在恢复校验账号、模式、人物、输入及请求编号；范围变化会作废旧请求。手动选择人物或模式会同步当前 URL，刷新不会退回旧范围。
3. **报告摘要截断和刷新丢对话**：原先 1100 字报告摘要只传前 600 字，报告入口刷新又清空消息。现在最多用两个 600 字条目传递摘要；同一报告恢复消息，新报告清空旧消息；请求按 UTF-8 字节压到 11 KB 以下。
4. **录音异步回填与资源残留**：补充采集代次、隐藏页清理、账号代次校验、迟到权限结果关闭、设备自然停止、初始化失败关闭流和 AudioContext；旧请求不能回填新账号。
5. **网页语音交互不完整**：增加免提／耳机选择和已验证的回声过滤，持续允许非回声的用户语音；增加明确开通／到期／余额错误及“先预留、生成语音后结算、未回应退款”的说明。
6. **语音结束竞态**：关闭前同步移除所有资源引用，关闭期间不允许新通话；旧异步清理不会关闭后来创建的设备。重复 `session.updated` 不重置 3 分钟计时。
7. **小程序语音转文字丢人物**：已选人物时降级入口携带 `subjectId`，未选人物保持原 `/pages/chat/index?mode=chat`。
8. **既有语音测试夹具过期**：`test-voice-gateway.mjs` 缺少重构后的身份依赖，已补明确的隔离传输测试桩；真正身份和计费继续由 SQLite 测试覆盖。

仅重写聊天、语音两页的 WXML/WXSS，并修复上述一处语音降级路由。沿用已认可的明亮玻璃设计：`#f6f9fc` 珍珠白、浅冰蓝表面、`#3286a2` 蓝色动作、深蓝正文、蓝色 Orbit 标识和真实本地玻璃配图。保留原有状态条件、同意、错误、计费、复制、录音及通话事件。

## 验证边界

本任务未部署、未修改秘密配置、未调用真实付费模型，也没有主动启用真实麦克风。真实手机的扬声器音量、浏览器／微信声学回声差异仍需在用户同意后进行真机通话验收；自动化验证覆盖协议与设备生命周期，不能冒充真实声学测试。小程序视觉已完成代码与流程检查，真机键盘和渲染验收由主任务的最终预览流程负责。
