# 功能示意图与聚焦咨询 · 2026-10-09

## 用户确认

“其他界面多设计图标和图片”，图片明确为“功能示意图，抽象、有质感”。保留首页原玻璃双环及已认可的暖米白界面。功能优先，目标是减少理解和重复描述的负担。

## 设计规格

- 用途：各页面的图形说明当前任务，帮助区分分析、聊天、语音、人物、报告与账户。
- 方向：精致纸张与磨砂玻璃质感的抽象线条构成；不用卡通人物或真人室内照片。
- 色板：暖米白 `#F7F3EC`、深棕 `#3C342F`、赤陶 `#965A42`、香槟 `#C5A16B`、描边 `#DDCFC0`。
- 字体：沿用项目已批准的 `PingFang SC / Microsoft YaHei / Noto Sans SC`，不引入外部字体加载。
- 布局：配图位于标题旁或功能空状态，轻微不对称叠层；手机缩小配图，保证内容与主要操作优先。
- 实现：自有 SVG 与已有 Lucide 图标；辅助示意不模拟真实分析数据。短暂入场效果支持减少动态效果偏好。

## 既有能力与本轮增量

四步洞察、替代解释、消息构成环图、人物趋势、整份报告追问、实际反馈复盘均已存在。本轮增加的是具体洞察到具体问题的连续操作、资料检索与预算排序的实际修正，以及各页面差异化的功能图形，不把既有功能重新描述为新增。

本文件的参考点不代表模型判断准确率或用户关系结果已经得到验证。

## 用户追加：主图融合与配色

用户指出玻璃主图与背景融合不足、米色偏深、整体缺少配色层次。因此在保留原图的前提下，将大面积背景收敛为瓷白 `#FBFAF7` / 日光白 `#F8FAFB`，阅读面板为白色；淡杏 `#F4E7DA` 与雾蓝 `#E9F2F5` 仅作局部辅助，正文 `#34434A`、辅助文字 `#5E6970`，主操作保留陶色 `#965A42` 配白字。通过同色底与边缘渐隐改善主图融合，不重新生成或替换原图。

## 实际功能与验证

- 精确洞察追问：选择哪条推测、哪一步，就优先带那部分依据到聊天。首次带入问题可编辑；刷新保留修改，清空后不会重新填回；不自动发送。
- 已保存资料按当前问题选择相关原话和实际反馈，同一建议只使用最新版反馈。旧模型评价置后并明确是推测。
- 原话、反馈和资料以完整条目按预算打包。原有 700 / 1000 / 1100 / 1800 / 4200 字预算不变，移除上层对结构化资料的二次粗暴截断。
- 深层判断指引补充真正影响下一步的关键未知、可区分解释的后续观察，以及同人、同事项、可比时间与口径的前后说法核对。
- 新增实际 SQLite 和真实提示构造路径测试 10/10；既有截图等回归 206/206；相关反馈、资料恢复、深层判断、技能和沟通测试通过。模型响应为替身，没有开展真实付费模型准确率实验。
- 浏览器洞察追问 10 组、聊天／语音 13 组通过，覆盖选中第二条假设、身份隔离、存储失败、草稿恢复和既有计费重试。
- 8 种功能 SVG 已接入网页，源图透明 PNG 同步小程序源页；首页原玻璃图保留。第一轮 24 个页面与宽度检查无横溢、图形可见，发现报告列表主按钮字色对比问题后修复；最终调色后继续定点复查。
