# 问成子全流程验收与优化 · 2026-10-16

## 本轮范围

网页版首页入口 → 问成子 → 添加截图/粘贴/拖放 → 确认双方与费用 → 回答 → 追问 → 离开返回/刷新 → 新对话；另测公开案例入口、失败退款与重试、报告带入上下文、桌面和手机窄屏。

全部提问材料均为虚构。真实模型测试在隔离的浏览器上下文使用已授权的 chengyi01 会话，不修改用户原窗口的对话、人物、报告或采集材料。

## 已发现并修复

1. **切换题型丢截图**：有截图或未完成请求时先确认；取消后保留图片、内容及原重试编号。
2. **截图不能核对**：点击缩略图打开大图，可切换适合屏幕/放大文字；关闭或 Esc 返回原位置。
3. **重试含义不明**：网络中断时明确显示“重试本次提问”和“继续原请求，不会重复扣费”。
4. **退款后多报错一次**：服务端只在数据库确认退回后标记 released，前端当次清理旧编号；退款状态未知时仍保留原编号。
5. **文字追问丢引用**：可核对用户历史原话，不再把当前追问问题作为默认依据；不采用智能体历史回答充当原话。
6. **报告追问返回后丢背景**：从普通问成子入口回来，恢复同账号的报告摘要、人物和草稿。显式另选人物/题型/场景不继承旧报告。
7. **短答仍像长报告**：回复改为短句卡片加复制；正文统一为 16px，去掉完整报告才需要的多层说明。
8. **擅自推定日期与催促压力**：约束回答区分替代日期、具体时刻和双方约定；未明确当前日期时不改成“今天/今晚”，不无依据要求延迟澄清；用户要一句就不展开多份话术。

3 次请求，总计 15 积分；余额 9865 → 9850。返回/刷新未产生额外请求或扣费，另开对话没有旧图片或上下文。真实返回发现了第 7、8 项，后续已修正界面与提示要求；最终提示词未再次收费调用，不能将本次样本视为所有模型回答质量的保证。
