# 个性化分析与便捷档案 · 2026-10-14

## 本轮交付

- “与你有关”：聊天、朋友圈、主页报告显示双方有出处的共同点、相处差异与可聊话题。只出现一方的线索不会计入共同点；照片外观、表情包、转述不作为本人兴趣证据。
- 快速认识我：兴趣/期待/沟通标签、免费本人自述整理、可选语音转文字、已有资料截图导入。确认后才保存，部分修改保留既有资料及权重。语音沿用原转写价格与明确同意，失败重试保留请求编号。
- 打开旧报告时，在站内结合新确认的本人资料重新计算共同点，不重跑模型、不扣费、不改写历史报告。
- 同一人物记住明确选择的聊天方向；图片按内容去重、顺序可调整。采集导入保留账号/资料库/人物范围，刷新恢复原任务。
- 新聊天与此前材料自动对照；默认不再要求填写“后来怎么样”。重叠、日期不明、片段材料不画虚假的提升趋势。见面准备只预填草稿，发送前仍由用户确认。
- 人物对照入口前置到工作台首屏、人物页独立栏目、人物详情。结合本人期待给简明判断与下一步，仍可核对详细表格。
- 小程序报告、截图速览、朋友圈/社交资料页增加共同点组件。原生客户端代码已修改，本轮尚未上传新的小程序包。

## 资料处理边界

新增跨来源个人资料只用于站内比对，没有增加向千问发送的资料。既有截图分析与语音转写继续走用户预览/明示确认流程。授权暂停、撤回、换账号、换人物、明确关闭本人对照均有隔离；没有自动持久化猜测。
