- 登录后工作台：真实积分、人物总数、待确认资料、最近人物及报告；新账号给明确起步入口。游客首页继续保留品牌展示与原地注册。

- 分析：三步材料流程，拖放/粘贴/键盘上传，真实张数与费用，高级设置折叠，改变资料对象不清空截图；保留原计费、续传、补图和授权。
- 洞察：依据、深层解释、另一种解释、验证观察；提示和解析保留竞争解释与反证，不将猜测当事实。洞察画布、真实消息构成图、雷达维度与趋势节点支持交互；缺失数据保持缺失，不编造概率或可比趋势。
- 报告摘要可复制/下载；人物列表可搜索筛选、跳转待确认资料；聊天首屏先看到输入框，场景练习带可编辑草稿而非自动扣费发送。
- 语音：免费麦克风检测、真实音量、即时手动打断、服务端倒计时、识别失败重说、正常结束、当页转写与用户主动转文字咨询。有效音频成功交付才结算，无回答释放预留积分。
- 默认声音通过用户明确授权的录音创建原生 Qwen Omni 音色。网页和小程序使用同一网关配置；原录音及参考样本未作为公开网页资源发布。
