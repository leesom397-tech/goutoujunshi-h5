# 小程序 1.0.78：手机截图与电脑完整报告

## 产品流程

首页主入口为「关系透视」，分析中心明确两类材料：

- 手机上传聊天、朋友圈或主页截图：生成**本次截图解读**。仅覆盖实际提供的材料，不声称读取手机全部微信历史。
- 电脑助手导入聊天、转写语音、可见朋友圈：生成**完整关系报告**或**完整朋友圈报告**。小程序关联电脑使用的同一账号后，可查看已同步材料，也可确认报价后发起完整分析。

查看已有报告免费。报告保留真实生成时间和材料范围，任务完成后主按钮为「查看完整报告」。

### 给已有完整报告补截图

从完整报告进入「补聊天截图／补朋友圈截图」，固定原人物和原报告。服务端核验同一账号、同一有效人物及已完成的完整报告；旧报告的有依据摘要作为背景加入现有截图解读调用，不额外请求一次模型分析。

新结果标为**补充解读**，显示原完整报告生成时间和返回入口。旧报告保持不变。本次截图不会冒充全量重新分析，也不会悄悄改变全量统计。需要更新电脑原文的完整报告时，从资料库另行核对范围、确认费用。

旧报告删除、重关联或内容改变时，未完成补充任务停止并按原任务退款机制处理。任务重试绑定原报告版本，不能跨账号或跨人物复用。
