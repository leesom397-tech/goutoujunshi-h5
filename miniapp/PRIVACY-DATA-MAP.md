# 小程序数据处理事实核对底稿（非法律声明）

核对范围：2026-10-03 的原生体验版 `1.0.28` 及其服务端代码；`1.0.28` 在实时通话前先申请 `scope.record`，不改变语音流向或本站保存范围。语音功能虽已进入体验包，仍待 iOS/Android 真机验收。此表供企业负责人核实平台隐私指引，不应原样视为合规结论，也未提交微信后台。

| 项目 | 当前代码行为 | 接收方／保存 | 用户控制与未核实点 |
| --- | --- | --- | --- |
| 微信身份 | `wx.login` 的临时 code 由服务端向微信换取 OpenID；默认映射到独立小程序身份，也存在用户另行明确关联网页 LoveTalk 账号的历史接口。客户端只拿到随机会话令牌。 | 微信接口、本站 Cloudflare D1；令牌哈希存库，服务端会话 7 天到期。OpenID 映射没有 7 天自动到期。 | 首页自动发起登录，无手机号授权弹窗。当前原生包无完整账号注销入口；“清空档案”仍保留登录身份。注销设计必须区分独立身份和已关联网页账号，不能跨账号误删。 |
| 用户选择的聊天截图 | 用户从相册主动选一张 JPG/PNG（上限 5 MB），确认材料权利和本人左右位置后，客户端将原图发给本站截图接口，本站再发阿里云百炼识别。 | 本站不把原图作为报告或长期档案保存；请求处理期间经过 Cloudflare Worker 和阿里云百炼。阿里云侧的处理／留存条款需企业核对。 | 上传前需明确勾选。未验证真机系统权限弹窗、失败重试或第三方实际留存。不得称“原图完全不经服务器”。 |
| 截图识别文字与报告 | 模型提取双方气泡并生成逐句分析；聊天线程和报告按 7 天失效，定时任务删除到期数据。 | Cloudflare D1；分析由阿里云百炼处理。 | 用户可在档案中删除对象及关联报告，或清空全部档案和报告。到期清理有代码与定时任务，但生产实际执行仍需运维验证。 |
| 人物档案 | 用户单独同意后填写对象称呼、备注；若已选档案且截图有明显事件，最多两条原话线索会先作为“待确认”保存，用户可确认或忽略。 | Cloudflare D1；没有与 7 天报告相同的自动删除期限。 | 可暂停、撤回档案同意、删除对象、清空档案。暂停或撤回不是立即删除；待确认线索虽未作为确认事实使用，仍已在数据库保存，不能写成“确认前完全不保存”。 |
| 打字咨询 | 用户单独确认后，当前输入及所选对象已确认的档案摘要发送阿里云百炼生成建议。该原生接口不将本次原话或结果写入报告／档案。 | 请求经 Cloudflare Worker 到阿里云百炼。 | 不选档案则不带对象档案。阿里云侧留存条款待企业核对。 |
| 手机号、定位、身份证、昵称头像 | 当前 `1.0.27` 原生页面未找到这些信息的授权或采集调用。服务端保留一个尚无前端入口的可选手机号换号接口，若以后启用仅保存尾号和验证时间。 | 当前原生用户路径不应声称这些字段均为必需。 | 微信后台现有隐私指引仍列出旧业务用途，需负责人按实际功能逐项调整；不能仅凭代码静态检查推断所有平台声明可以直接删去。 |
| 按住说话转文字 | 用户勾选本次处理同意并按住说话后，小程序录制最长 30 秒 WAV，经本站转交阿里云百炼识别；识别结果只填入可编辑草稿，不自动发送给咨询模型。 | 录音经 Cloudflare Worker 与阿里云百炼；本站不写入 D1 或对象档案。阿里云侧的处理和留存条款待负责人核对。 | 页面离开时停止录音并丢弃未完成片段。用户可修改或删除草稿；点击「开始解读」需再次满足文本输入与本次同意。新功能尚缺真机验收。 |
| 实时语音 | 用户单独勾选后先授权 `scope.record`，再开始 3 分钟内的通话；小程序持续采集 PCM 分片，经鉴权 Worker WebSocket 代理发给阿里云百炼；模型流式返回 PCM 和即时转写。用户可选择不使用档案；若选择对象，须另行勾选同意，本次才会读取该对象已确认的档案摘要并发送给阿里云百炼作为对话背景。 | 通话音频、即时转写及用户本次授权的档案摘要经过 Cloudflare Worker 和阿里云百炼；当前代码不将本次通话写入 D1 或人物档案。原有人物档案仍按档案规则保存。服务商侧留存规则待负责人核对。 | 拒绝麦克风授权则不建立模型连接；结束通话或离开页面停止麦克风和连接。未选对象或未授权不会读取档案。微信后台 `wss://coach.lovetalk.love` 合法域名已只读核实，但仍需核对录音和档案用途的隐私指引及 iOS/Android 真机的录播并行、打断效果；免提回声过滤仍未通过真机验收，不能宣传为已修好。 |
| 社交软件资料截图体检 | 用户每批选 1–4 张资料图，所选原图单张上限 12 MB、压缩后本批上传合计上限 36 MB；最多累计 8 张。小程序先将较大原图压缩到约 1.5 MB 内；每批确认资料提供权及阿里云识图范围后，将本批压缩图经本站 Worker 发给阿里云百炼。下一批只携带前批分析摘录，不重传前批图片。服务端不写入图片、识别文字或报告。 | Cloudflare Worker 转送阿里云百炼；本站 D1 不保存本次截图或体检结果。阿里云侧留存条款仍待负责人核对。 | 每批单独勾选授权；压缩后的文字清晰度须真机核对。合并结果仍只是未核实的资料整理，不能据此认定自述真实。用户另行勾选后才能建立人物档案，且仅保存手填称呼，不自动把截图自述入档。小程序平台隐私指引及真机验收仍待核对。 |

提交审核前需要企业负责人核实：处理者名称与联系方式；微信隐私指引中的信息类型和用途；阿里云百炼及 Cloudflare 的实际处理范围与留存承诺；档案和待确认线索的保存期限；用户账号注销及数据请求渠道；当前认证、备案和账号介绍。核对后再由有权主体修改、预览并提交后台声明。当前体验版还缺 iOS/Android 真机端到端验证。

2026-10-03 再次只读核对微信后台：账号设置仍显示「微信认证：已到期，小程序发布前需完成微信认证」「小程序备案：未备案，需先完成微信认证」；服务类目仍含「社交 > 婚恋」。隐私指引状态虽为「已更新」，对已打开编辑页的 12 个可见表单字段仅做关键词存在性检查：仍能匹配旧业务用途「提前上传」「登录或者注册」「显示距离」「实名认证」，未匹配「语音」「录音」「阿里云」「百炼」「7 天」「档案」。这不是完整法律审查；关键词未匹配只说明这些可见字段没有相应文字，不能证明指引其他位置绝对没有。没有修改、保存或提交微信后台。

在 `1.0.28` 成为体验版后再次只读检查，上述 12 个可见字段仍未匹配「语音」「录音」「阿里云」「百炼」。腾讯云的[小程序隐私保护指引适配说明](https://cloud.tencent.cn/document/product/1301/97930)提示，平台隐私接口需按实际处理的信息类型配置指引，并在用户同意后调用。由此只能推断麦克风授权失败可能与平台披露有关，**不能在未取得真机错误码和完整平台指引前将其定为根因**。企业负责人需先核实实际处理方、用途与留存规则，再决定并提交准确的平台字段。

2026-10-03 生产 D1 只读汇总检查：过期报告、过期聊天线程、过期小程序会话各为 0 条；查询不返回用户身份或聊天内容。它只能证明查询当时没有这些到期残留，不能单独证明定时任务每次都成功或第三方服务已经删除副本。
